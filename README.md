### 🤖 Autonomous Agent: ST-Scout (`st_scout_agent.py`)

The **Search Telemetry Research Scout (ST-Scout)** is a lightweight Python agent with live tool connections:
1. **Perception:** Ingests local DuckDB tables across millions of rows to isolate statistically suppressed search queries.
2. **Observation:** Queries live competitor SERPs to inspect top ranking titles and content structures.
3. **Reasoning & Guardrails:** Enforces a 60-character title limit and verifies metric sanity.
4. **Action:** Stages structured Markdown and JSON action briefs to disk.

#### Quickstart:
```bash
python st_scout_agent.py
```
