FlyRank AI — Industrial ML Ranking System

A production-scale machine learning benchmark built on 78.8 million rows of Search Console search query logs, featuring out-of-core DuckDB streaming, calibrated LightGBM rankers, and domain-stratified GroupKFold cross-validation.

Machine Learning Systems DuckDB LightGBM Pareto Frontier Research Paper

Empirical Benchmark of Scalable Machine Learning Pipelines for Out-of-Core Industrial Analytics

When business teams enter cold-start search domains, naive pandas dataframes crash on out-of-memory errors, and random k-fold splits leak domain signals into test sets. This system solves both: streaming Parquet batches via DuckDB in 4.18s, balancing sparse conversion targets (0.007%), and establishing Pareto-optimal trade-offs between high-value acquisition and compute cost.
